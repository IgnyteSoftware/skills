# Specification comparison samples

These are synthetic evaluation inputs and agent-generated outputs, not production
application code. The baseline sample came from the published skill revision; the
candidate sample came from the later plain-English specification run after review
fixes. See [the report](../REPORT.md) for comparison method and limitations.

Client labels were generalized for publication. The original output hashes are in
[results.json](../results.json). Local `.agents/skills` paths mentioned in handoffs
describe instructions used during execution; those copies are omitted here.
